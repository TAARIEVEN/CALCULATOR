1. Derivative Rules & Identity Statements

The derivative of a function measures the rate at which the function value changes with respect to a change in its input value.

Power Rule: d/dx (x^n) = n · x^(n−1)
Product Rule: d/dx (uv) = u'v + uv'
Quotient Rule: d/dx (u/v) = (u'v − uv') / v²
Chain Rule: d/dx [f(g(x))] = f'(g(x)) · g'(x)
